社群自動化整理探索

AI Agent 在 Facebook 貼文整理上的實踐與極限

Automation Capability

社群整理的可能與邊界

剖析瀏覽器模擬的極限，以及面對安全防禦的現實策略。

核心難點與瓶頸
✗
反爬蟲機制 (Anti-Bot)：Facebook 擁有全球最頂尖的反爬蟲與自動化檢測系統。
✗
雙重驗證 (2FA)：在 Headless 模式下，異地登入極易觸發人臉驗證或手機簡訊驗證，造成自動化斷點。
✗
非公開貼文：社團、私人貼文必須登入才能存取，這對無狀態的 Sandbox 構成登入瓶頸。
可行解決方案
✓
無登入公開抓取：利用 Agent 瀏覽器技術 (Chrome+CDP) 抓取公開粉絲專頁或 RSS 來源。
✓
半自動引導登入：Agent 提供螢幕截圖與即時 DOM 交互，引導用戶進行手動登入與授權。
✓
API 官方接口：使用 Meta 官方 Graph API 進行結構化貼文檢索，取得最穩定的資料流。

Architecture

多 Agent 任務指派流程

解構主 Agent (Parent) 與子 Agent (Subagent) 的協作分工

👑
Parent Agent
主控決策：直接與用戶對話，解析語意與需求，制定全域計畫，並進行高難度的決策。
➔
⚡
Subagents
併發執行：如 research 或 self，被主控端透過 invoke_subagent 呼叫，在隔離的工作區並行工作。
➔
💬
Message Loop
自動非同步回呼：子 Agent 完成後，透過 send_message 將結果推回，系統自動喚醒主 Agent，不需輪詢。
底層本質：系統的最底層並非 Agent 本身管理，而是由背後的 Agent 框架進行 Sandbox 隔離、網路管控與 CDP (Chrome DevTools Protocol) 接口綁定。這使得 Agent 專注於任務推導，底層專注於安全隔離。
